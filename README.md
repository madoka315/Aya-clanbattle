# Aya-clanbattle

《公主连结》公会战机器人：**OneBot v11 反向 WebSocket + Web 面板**。单进程、单机器人账号。  
历史数据可从 yobot_remix 迁移；

## 功能一览

### 群聊

- **出刀**：申请出刀（`进1`~`进5`）、报伤害/更新出刀、报刀、尾刀、撤销、挂树、SL
- **预约**：`预约N[:留言]`、`取消预约N`；对应王出现时 @ 提醒，合刀预约静默
- **查询**：`状态`、`查刀`（当日出刀表）、`出刀记录`、`刀伤`（个人出刀表）
- **统计**：`战报`/`统计`
- **计算**：`合刀计算`、`垫刀计算`、`补偿轴`
- **出图**：樱花手帖风格

### 网页

- SSE 实时同步，与群指令共用规则层
- 申请、报刀、尾刀、撤销、挂树、SL、预约、改状态、催刀、成员与档案管理等均可在网页完成
- 登录：私聊「登录」获取一次性链接，或「重置密码」后用密码登录；7 天会话，写操作 CSRF 校验
- 支持游客与外部统计 API
- 统计页：每日刀数/伤害、成员贡献榜、各王主力、出刀时刻分布、最速/最慢下班榜
- 每天 05:05 自动同步群名/成员名片/头像，并可自动拉取当期 boss 数据（也可在站点管理里手动拉取）

## 与 yobot_remix 的关系

- 风格完全参照yobot_remix，无缝上手
- 状态归一化为 SQLite 表（血量/挑战者/预约），不再使用 JSON 文本字段
- 提供 yobot_remix 数据迁移脚本（见「数据与迁移」）
- 优化性能、网页面板操作、统计、UI等
- 已移除 yobot 的旧指令：`手册`、`刷新`、`业绩`/`业绩表`（现为 `查刀`）

## 快速开始

要求：Python 3.11+。

```bash
python -m pip install -r requirements.txt

cp config.example.json config.json
# 编辑 config.json：access_token、public_address、super-admin 等

python main.py          # 默认 http://localhost:9223/
```

机器人侧（NapCat / 兼容 OneBot v11 的实现）配置**反向 WebSocket**：

```
ws://<部署机地址>:9223/onebot/v11/ws
```

`access_token` 与配置一致；消息格式使用 array。除 `/onebot/v11/ws` 外也兼容 `/ws`、`/ws/`。

### 字体与头像

- 字体：优先读取 `aya_clanbattle/fonts/msyh.ttf`，也可在 `config.json` 用 `font_path` 指定；  
  都没有时回退系统中文字体（Windows 微软雅黑 / macOS 苹方）
- emoji：彩色 emoji 依赖系统 emoji 字体（Windows 自带 Segoe UI Emoji）；缺少时自动退化
- 头像：默认缓存到 `data/user_profile/<qqid>.jpg`，渲染前按需下载，7 天过期；可用 `avatar_dir` 改路径

## 群聊指令

`< >` 表示任取其一，`[ ]` 表示可省略。未识别的消息静默不回复。

### 出刀与状态

| 指令示例                                 | 说明                               |
| ------------------------------------ | -------------------------------- |
| `创建国服公会` / `创建日服公会` / `创建台服公会`       | 初始化本群公会战；韩服暂不支持                  |
| `加入公会` / `加入公会 @某人`                  | 登记会战成员；群管理员可代加                   |
| `加入全部成员`                             | 群管理员一键登记本群全部成员                   |
| `进1` ~ `进5` / `申请出刀 2`               | 申请挑战；补偿写 `补`/`b`/`bc`，`@某人` 为代申请 |
| `更新出刀：5s500w 留言` / `报伤害 5s500w`      | 更新剩余秒数、伤害、留言；纯文字=只改留言            |
| `挂树1` / `挂树 1:留言` / `挂树 @某人`         | 挂树；不带王号则使用当前申请的王                 |
| `查树` / `查1` ~ `查5`                   | 查询挂树；`查N` 同时显示该王挑战者              |
| `报刀 100w` / `报刀 -1 100w` / `刀1 100w` | 上报伤害；已申请可不写王号                    |
| `报刀 100w补` / `报刀 100w @某人 昨日`        | 补偿刀 / 代报 / 补昨日（仅今日无记录时可用）        |
| `尾刀` / `尾3` / `尾刀 3 @某人 昨日`          | 击败 boss 收尾                       |
| `撤销`                                 | 撤销最后一刀；管理员可撤他人                   |
| `SL` / `SL?` / `SL @某人`              | 记录 / 查询 SL                       |
| `不打了` / `不进了 @某人`                    | 放弃当前申请                           |
| `状态`                                 | 五王实时状态图                          |
| `面板` / `后台`                          | 返回网页面板地址                         |

### 取消

| 指令示例                       | 说明              |
| -------------------------- | --------------- |
| `取消出刀` / `取消申请` / `取消申请出刀` | 取消当前申请          |
| `取消报伤害` / `取消SL`           | 清除报伤害 / 取消今日 SL |
| `取消预约3`                    | 取消对 3 王的预约      |

### 预约与查询

| 指令示例                              | 说明              |
| --------------------------------- | --------------- |
| `预约3` / `预约 3:等一只大蛇`              | 预约 3 王，出现时 @ 提醒 |
| `预约4:合` / `预约合4`                  | 合刀预约；成功与提醒均静默   |
| `预约表`                             | 查看全部预约          |
| `查刀`                              | 当日出刀总表图         |
| `出刀记录` / `出刀情况` / `出刀状况` / `出刀详情` | 当日出刀文字汇总        |
| `刀伤` / `刀伤 @某人`                   | 个人当日出刀表图        |
| `战报` / `统计`                       | 当前档案统计长图        |
| `ver` / `V` / `version`           | 机器人版本           |

### 管理与计算

| 指令示例                     | 说明                               |
| ------------------------ | -------------------------------- |
| `重置进度`                   | 群管理员/主人；结算并新建空档案，旧档案保留           |
| `权限 @某人`                 | 群管理员授予/调整公会战管理权限                 |
| `合刀计算 50 60 70`          | 两刀合刀，分别给出谁先出时另一刀可获得的补偿秒数         |
| `垫刀计算 1700 1700 34 56`   | 总血、当前伤害、当前秒数、目标补偿秒数              |
| `补偿轴 121 118 110 107 58` | 按返还时间换算时间轴；分秒压成三位数（`107` = 1:07） |

## 网页与 API

- 登录：私聊机器人「登录」获取 60 秒一次性链接，或「重置密码」获取临时密码
- 权限：主人（authority 1）/ 公会战管理员（10）/ 成员（100）；网页管理操作要求管理员且为公会成员
- 游客：公会设置开启后，未登录也可读面板与记录
- 出刀记录 JSON API：`GET /clan/<群号>/statistics/api/`；可用 apikey（需开启 API ）访问，或已登录的公会成员/管理员直接访问

## 数据与迁移

- 数据库为 SQLite（WAL），首次启动自动建表；实时状态与出刀日志分表存储
- 档案：每次重置会生成新档案号，旧档案快照保留，可在网页切换
- 从 yobot_remix 迁移：

```bash
python -m aya_clanbattle.migrate_from_remix <yobot_remix.db 路径>
```

迁移会先做一致性快照，再导入 guild / 成员 / 出刀记录 / 档案快照，并逐档核对数量。
